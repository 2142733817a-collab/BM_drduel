# 服务器提示语言

对局提示使用服务器进程的 `ADIMI_MESSAGE_LANGUAGE` 环境变量选择语言。此设置对该服务器中的所有玩家生效，不读取玩家客户端的游戏语言，玩家不需要安装额外客户端 Mod。

- 不设置、留空或设置为 `zh`：简体中文（默认）。
- 设置为 `en`：英文。也识别 `English`、`en-US` 等英文语言标识，忽略大小写。
- 其他值回退为中文。

语言在服务端进程启动时确定。修改配置后，需要重启游戏服务器进程；只在当前终端设置变量不会改变已经运行的进程。

Linux 使用 systemd 时，可在该服务的配置或覆盖文件中设置：

```ini
[Service]
Environment=ADIMI_MESSAGE_LANGUAGE=en
```

修改 systemd 配置后，部署者应重新加载 systemd 配置，并重启对应的游戏服务器服务。恢复中文时将值改为 `zh`，或移除该环境变量。

Windows 使用 PowerShell 启动服务器时，可在启动服务器的同一个 PowerShell 进程中先设置：

```powershell
$env:ADIMI_MESSAGE_LANGUAGE = 'en'
```

之后按原有方式启动服务器。恢复中文时设置 `$env:ADIMI_MESSAGE_LANGUAGE = 'zh'`。

提示的段落、标题和重点数字沿用现有布局与颜色。玩家昵称保持原样；第三方 Mod 未提供英文原文的兵种名称仍可能保留原名。
